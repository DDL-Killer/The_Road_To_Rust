## 函数

1. 名称
2. 参数
3. 返回类型
4. 函数体

### 函数&变量的命名规范:snake case:

* 所以字母都小写
* 单词之间用"_"链接

### 参数

* 必须声明每个参数的类型 参数名:类型
* 多个参数需使用","分开

## 语句和表达式

* 语句:执行某些操作的指令,不返回值
* 表达式:计算并返回一个结果值

函数体由一系列语句组成,可由表达式结尾

```rust
fn main(){
	let y = 6;
}
```

## 函数的返回值

```rust
fn five() -> i32{
	5
}

fn main(){
    let x = five();
    
    println!("The value of x is:{x}");
}
```

* 使用"`->`"声明函数返回值的类型
* 返回值:
  * 可以使用`return`返回值
  * 函数体中最后一个表达式的值
